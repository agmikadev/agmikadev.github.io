# Plan 04-03 — Keyboard navigation and focus management

**Goal:** A keyboard-only user can reach the SALTO trigger, the AI belt, every planet
and the HUD controls, and never loses focus after a screen change.

**Requirements:** UX-03

## Tasks

- [x] Make the belt hitbox tabbable, expose it as a button and open it with Enter/Space.
- [x] Give planets button semantics and open them with Enter/Space.
- [x] Move focus to the HUD back control when the HUD is opened by keyboard.
- [x] Restore focus to the planet/belt when the HUD closes.
- [x] Focus the SALTO region on open and restore focus to the SALTO trigger on close.
- [x] Keep `Escape` closing the HUD and SALTO.

## Verification

- Playwright: Tab reaches the belt; Enter opens the belt HUD; Escape closes and
  restores focus; same for a planet; SALTO closes with Escape and restores focus.
